---------------
->DIV is block level element and span is inline element
Block element always starts on a new line and takes off the full width available
ex :- <aside> <article><address><table><section><hr><header><ul>
->An inline element doesnt start on a new line and takes up as much width as required
Ex:- <a><abbr><br><span><time><textarea>
